# ZeroClick

Zero-latency mechanical keyboard and mouse sounds for Windows, built for gaming.

**Download:** grab `ZeroClick.exe` from the [latest release](https://github.com/midnightvr123-tech/ZeroClick/releases/latest), then run it. All sounds are built in.

Already have it? Open **Settings -> Updates -> Check for updates** in the app.

- Native WASAPI low-latency audio (no Electron), Raw Input (no hooks, nothing injected into games)
- Real recordings: 28 keyboard packs (Topre, Holy Panda, Deep Thock, Cherry MX...) and 11 gaming mice (G Pro X Superlight, DeathAdder V2 Pro, Model O, G502 X...)
- Thock slider, stereo placement, per-key variation, mute hotkey, game rules
- Turn a phone recording of any mouse or keyboard into a pack

Sound credits and licenses are listed in the app (About page) and inside each pack.
